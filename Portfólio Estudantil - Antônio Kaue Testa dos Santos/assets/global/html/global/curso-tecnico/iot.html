Acender LED.

Neste projeto, montei um circuito básico com Arduino UNO para acionar um LED. A proposta era entender na prática como conectar os componentes eletrônicos e como o Arduino controla uma saída digital. A partir dessa experiência, comecei a me familiarizar com a montagem em protoboard e com o funcionamento elétrico de um LED.

Protótipo da montagem física: Utilizei uma protoboard com Arduino UNO, LED e resistor, ligando o LED a uma porta digital para permitir o acionamento.

Código: Esta aplicação não exigiu um código específico.

Justificativa: Esse foi meu primeiro contato prático com eletrônica e Arduino, uma base essencial antes de avançar para projetos mais complexos de Internet das Coisas.

Semáforo

Para essa atividade, montei um protótipo de semáforo com Arduino UNO e LEDs. O foco foi entender de que forma componentes eletrônicos podem ser controlados via código. Foi uma boa oportunidade para conectar a parte física da montagem com a lógica por trás de sistemas automatizados que vemos no dia a dia.

Protótipo da montagem física: Usei uma protoboard com LEDs representando cada sinalização do semáforo, conectados às portas digitais do Arduino para testar o funcionamento.

// controlando o pino através de uma variável

int pino = 10;

void setup() {
    pinMode(pino, OUTPUT);
}

void loop() {
    digitalWrite(pino, HIGH);
}

Justificativa: Essa atividade uniu programação e eletrônica em uma situação prática, mostrando como comandos programados são capazes de controlar automaticamente componentes eletrônicos.

Controle de LED com Botão

Nesse projeto, montei um circuito com Arduino UNO para controlar um LED usando um botão. A ideia era explorar a relação entre entradas e saídas digitais e treinar a lógica necessária para acionar um componente eletrônico a partir de uma interação externa.

Protótipo da montagem física: A montagem contou com Arduino UNO, protoboard, LED, resistor e botão, todos conectados às portas do Arduino para os testes de acionamento do circuito.

// C++ code

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(1000);

    digitalWrite(LED_BUILTIN, LOW);
    delay(1000);
}

Justificativa: Esse desafio ajudou a fixar o entendimento sobre controle de saídas digitais e como comandos de programação definem o comportamento de um componente eletrônico.
